## Summary

This plan states how `rom-manager` delivers the rows of `CONN-ROM-MANAGER-COMPETENCY-OPERATIONS`. The live caller is the `rom-manager` console script. The owner is the `rom_manager` package. The rows reuse the `scion-sdk` helpers and add no second authority. The plan changes no runtime code.
